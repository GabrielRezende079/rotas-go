# Dados locais

Esta pasta recebe os artefatos gerados por `scripts/prepare_es_data.sh`:

- `es-latest.osm.pbf`: extrato estadual publicado por OpenStreetMap France;
- `es-road.graph.gz`: grafo compilado consumido pela API Go.

Os arquivos grandes são ignorados pelo Git. Execute o script de preparação para
reproduzi-los a partir das fontes públicas.
